# OpenBomber v2: план переписывания

Ветка `rewrite/v2`. Старый код лежит в `legacy/` только как справочник: его не импортировать и не править.
**В `main` не пушить:** CI (`.github/workflows/main.yml`) деплоит на прод при пуше в `main`.

## Стек

| Слой | Выбор | Почему |
|---|---|---|
| Монорепо | Bun workspaces (`packages/*`) | как и раньше |
| Симуляция | `@ob/game`: чистый TS без зависимостей, детерминированный fixed-step 60 Гц | один и тот же код на сервере, в предсказании клиента и в офлайне с ботами |
| Сервер | Colyseus 0.18 (`@colyseus/core`, `ws-transport`, `schema` 5) на Bun | комнаты, матчмейкинг, реконнект, delta-патчи |
| Рендер | Pixi.js v8 | атласы из new-openbomber уже в его формате; свой WebGL2 ничего не даёт для 2D-тайлов |
| UI | Preact + @preact/signals, DOM поверх canvas | лёгкий, сигналы удобны для HUD |
| Звук | WebAudio, всё процедурное (синтез SFX и генеративная музыка), без аудиофайлов | |
| Ввод | клавиатура, геймпад, тач (плавающий джойстик и кнопки), вибрация | |

Правила для агентов:
- Пишите только в своих папках. Нужно изменить контракт? Опишите это в `docs/requests/<agent>.md` и временно обойдите у себя.
- Зависимости уже установлены. Новую ставить только при реальной необходимости, через `bun add` в своём пакете.
- Не коммитить и не пушить: коммиты делает координатор.
- Импорт игры: `import { ... } from '@ob/game'`.

## Коллизия (из new-openbomber)

Игрок — круг `PLAYER_RADIUS = 0.25` тайла. Каждый тик: сдвиг на `input * speed * dt`, затем для 3×3 тайлов
вокруг `round(pos)` суммируется выталкивание `cir2sqr(pos, r, tile, 1)` для Wall/Brick (Brick пропускается
при Ghost) и `cir2cir(pos, r, bomb, BOMB_RADIUS)` для бомб, кроме тех, где игрок в `passers` (или у него BombPass).
За счёт этого игрок мягко соскальзывает с углов и легко попадает в коридоры. Вдобавок нужен corner-assist:
если игрок упирается в стену, а соседний тайл по перпендикуляру свободен, его плавно подтягивает к центру
коридора. Игрок удаляется из `passers`, как только отходит от бомбы дальше `BOMB_RELEASE_DISTANCE`.

## Геймплей

**Кнопки:** `Bomb` и `Action`. Action контекстная: держишь бомбу → отпустил и бросил; есть Glove и бомба
под ногами или прямо перед тобой → схватить (зажать); есть Punch и бомба перед тобой → удар;
есть Remote → взорвать самую старую свою бомбу.

**Бомба:** ставится в `round(pos)`, если тайл свободен и лимит не исчерпан (не ставится при Constipation).
Есть LineBomb, и игрок стоит на своей бомбе → по нажатию Bomb ставится линия бомб по направлению взгляда.
- Огонь идёт в 4 стороны на `radius`. Стена гасит его, не занимая клетку. Кирпич разрушается, огонь
  останавливается (с Pierce идёт дальше). Буст сгорает и гасит огонь, но сначала у него идёт `protect`.
  Бомба детонирует цепочкой с задержкой `CHAIN_DELAY`.
- Летящие бомбы огонь не задевает. Скользящие задевает.
- Хитбокс огня прощающий: игрок погибает, если клетка `round(pos)` горит, или круг радиусом `0.6·PLAYER_RADIUS`
  пересекается с горящей клеткой.

**Kick:** игрок упирается в Idle-бомбу по направлению движения, и она скользит со скоростью `KICK_SPEED`
до препятствия: стены, кирпича, бомбы, буста или игрока.

**Glove / Punch:** бросок на `THROW_DISTANCE` (удар на `PUNCH_DISTANCE`) по направлению взгляда, прямо через
стены и кирпичи. Если клетка приземления занята (стена, кирпич, бомба), бомба отскакивает ещё на 1 тайл
(`BOUNCE_TIME`). За краем карты она переходит на противоположную сторону (wrap). Бомба, упавшая на игрока,
оглушает его на `STUN_TIME` и отскакивает дальше. Пока бомбу держат, фитиль стоит на паузе.

**Remote:** свои бомбы не взрываются сами (`fuse < 0`), только по Action (самая старая первой).
Страховка: через `REMOTE_BOMB_MAX_FUSE` взрываются автоматически.

**Crazy:** случайный фитиль в `[CRAZY_FUSE_MIN, CRAZY_FUSE_MAX]`, радиус от `r` до `r·CRAZY_RADIUS_MULT`,
с шансом `CRAZY_DUD_CHANCE` бомба не взрывается (`bombFizzled`).

**Бусты:**
- Стат-бусты действуют до конца раунда: BombUp, FireUp, SpeedUp, FullFire.
- Способности до конца раунда: Kick, Glove, Punch, Remote, Pierce, LineBomb, BombPass.
- Временные: Shield (блокирует один взрыв), Ghost (проход сквозь кирпичи; если время кончилось внутри
  кирпича, игрока выталкивает на ближайший пол), Crazy, Fire (скорость ×0.6, касание убивает других).
- Heart: +1 жизнь, респаун через `RESPAWN_DELAY` с неуязвимостью.
- Skull: случайное проклятие (Reverse, Diarrhea, Constipation, Slow, Fast, TinyFlame) на `CURSE_TIME`.
  Заразно: при касании копируется другому игроку, 1 с иммунитета от повторного заражения.
- Random: превращается в случайный другой буст.

Веса выпадения: BombUp 18, FireUp 18, SpeedUp 12, Kick 7, Glove 6, Punch 5, Shield 5, LineBomb 4, Skull 4,
Random 4, Remote 3, Pierce 3, BombPass 3, Ghost 3, Crazy 3, Fire 3, Heart 2, FullFire 1.
Бусты прячутся в кирпичах при генерации и хранятся во внутреннем состоянии sim, не в `WorldState`:
так их не подсмотреть через сеть.

**Смерть:** если есть жизни, тратится жизнь и запускается респаун. Иначе игрок выбывает и до 5 собранных
бустов разлетаются по случайным свободным клеткам. Убийство засчитывается владельцу огня.

**Раунд:**
- `Waiting`: игроков меньше `minPlayers`, свободная игра, мгновенный респаун.
- `Countdown`: 3 с, игроки заморожены на спавнах.
- `Playing`: длится `ROUND_TIME`.
- `SuddenDeath`: блоки падают по спирали снаружи внутрь, о каждом предупреждает тень (`FallingBlock.ttl`).
  Упавший блок убивает игрока под собой и уничтожает бомбы и бусты.
- Раунд кончается, когда живых ≤ 1 и ни у кого не ждёт респаун. Тогда `RoundOver`: `winner`, `wins++`,
  затем новый раунд с новой картой.
- Кто зашёл посреди раунда, смотрит как зритель (`inRound = false`).

**Карта:** столбы стоят там, где `x % 2 == 1 && y % 2 == 1`. Размер зависит от числа игроков: 2–4 → 15×13,
5–8 → 19×15, 9–12 → 23×17, 13–16 → 27×19. Спавны по углам, дальше равномерно, вокруг каждого
свободная L-зона 2 тайла. Кирпичи заполняют `BRICK_FILL`, бусты лежат в `PICKUP_FILL` кирпичей.

## Сеть

- Сервер: комната `battle`, `setSimulationInterval` 60 Гц, `patchRate = 1000 / PATCH_RATE`.
  Инпуты приходят пачками (`MSG.input`), лежат в очереди на игрока, за тик применяется по одному.
  Если очередь пустая, повторяется последний инпут. Если в очереди больше 6, лишние старые отбрасываются.
  Схема зеркалит `WorldState`. События уходят пачкой (`MSG.events`) раз за патч.
- Клиент (`NetSource`): свой игрок предсказывается через `predictMovement`. От последнего серверного
  состояния (ack по `ackSeq`) переигрываются неподтверждённые инпуты, ошибка сглаживается.
  Чужие игроки интерполируются с задержкой примерно 100 мс. Бомбы и огонь берутся из состояния.
- Матчмейкинг: быстрая игра через `joinOrCreate`; приватная комната с коротким кодом (это roomId,
  4–5 символов A-Z0-9); список публичных комнат; реконнект через `allowReconnection(20 c)`.
  Пока человек один, комнату добивают боты до `bots`.
- Сервер слушает `PORT` (по умолчанию 2567). Клиент берёт `VITE_SERVER_URL`, а без неё
  `ws(s)://<host>:2567` (в dev) или `wss://<host>/api` (в prod).

## Клиент

Интерфейсы описаны в `packages/client/src/contracts.ts`. Сессия связывает модули так:
`InputManager.sample()` → `GameSource.update()` → `GameRenderer.render(world)`;
`GameSource.drainEvents()` → `renderer.handleEvents`, `audio.handleEvents`, `input.vibrate`;
HUD-сигналы обновляются примерно 10 раз в секунду.

## Этапы

1. Параллельно: SIM, RENDER, AUDIO, UI (против контракта и моков).
2. NET (сервер и NetSource), как только готов SIM.
3. Интеграция `src/session`: офлайн с ботами и онлайн; плейтест в браузере, баги, полировка.
4. Деплой: новый CI (сборка клиента и сервера, bun вместо pm2 node). Только после ревью владельцем.
