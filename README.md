## Об игре

Ставь бомбы, ломай кирпичи, собирай бусты и оставайся последним живым. Раунды идут без лобби:
когда в живых остаётся один, камера улетает на новую карту, и через пару секунд начинается
следующий раунд. Если раунд затягивается, поле сужается кольцами: края по очереди засыпает
стенами, а перед этим они подсвечиваются красным. Карта растёт вместе с числом игроков:
от 13×13 для одного до 75×75 для 32.

- **Онлайн.** «Играть онлайн» — общая арена со всеми, кто сейчас на сайте. Своя комната для
  друзей по коду или ссылке, наблюдатели («Отключиться» / «Подключиться»), чат.
- **Discord.** Игра запускается как активность прямо в голосовом канале: вход через Discord,
  все из канала играют в одной комнате, друзей можно позвать из меню.
- **Одиночная игра.** До 7 ботов трёх уровней сложности, работает без интернета.
- **Где угодно.** Клавиатура, геймпад или тач-джойстик на телефоне, с вибрацией.

## Арены и погода

Каждый раунд арена новая. Форма: прямоугольник, круг, ромб или крест, и зона сужается по
форме арены. Тема: луг, осень, зима или пустыня, и местность вокруг арены тоже меняется.
Погода: ясно, дождь, гроза с молниями, снег, туман, ветер или ночь, когда видно только свет
от героев, бомб и огня. Дым от взрывов сносит ветром, герои оставляют следы на снегу и песке,
а звуки окружения меняются вместе с погодой.

## Управление

| Действие | Клавиатура | Геймпад | Телефон |
|---|---|---|---|
| Движение | `WASD` / стрелки | левый стик / крестовина | плавающий джойстик слева |
| Бомба | `Space` | `A` / `RT` | кнопка с бомбой |
| Действие (схватить, бросить, ударить, взорвать) | `E` / `Shift` / `J` | `B` / `X` / `RB` | кнопка с ладонью |
| Телепорт (когда есть заряды) | `R` / `K` | `Y` / `LB` | голубая кнопка |
| Чат | `T` / `Enter` | — | кнопка чата |
| Таблица игроков | зажать `Tab` | — | в меню |
| Меню | `Esc` | `Start` | `☰` |

Персонажи толкают друг друга, а коллизия мягкая: в коридоры легко зайти с угла.

## Разработка

Монорепо на [Bun](https://bun.sh):

| Пакет | Что внутри |
|---|---|
| [`packages/game`](packages/game) | Детерминированная симуляция (60 Гц) и боты, общие для сервера и клиента |
| [`packages/server`](packages/server) | Авторитетный сервер на [Colyseus](https://colyseus.io): комнаты, синхронизация, античит |
| [`packages/client`](packages/client) | Рендер на [Pixi.js v8](https://pixijs.com), интерфейс на Preact, процедурные звуки, ввод |

Сервер считает всю игру сам. Клиент присылает только ввод: своё движение он предсказывает
тем же кодом симуляции, а чужих игроков интерполирует. Тот же код запускает одиночную игру
прямо в браузере.

```bash
bun install
bun run dev:server   # игровой сервер на ws://localhost:2567
bun run dev:client   # клиент на http://localhost:8080 (с ?mock интерфейс работает без сервера)
bun run test         # тесты симуляции и сервера
bun run build        # packages/client/dist и Node-бандл сервера в packages/server/dist
```

Стенды разработки: `/render/dev.html` (рендер на локальной симуляции с ботами)
и `/audio/dev.html` (все звуки).

<details>
<summary>Переменные окружения сервера</summary>

| Переменная | По умолчанию | |
|---|---|---|
| `PORT` | `2567` | Порт |
| `HOST` | все интерфейсы | Адрес |
| `BASE_PATH` | `/api` | Префикс, который тоже принимается (за nginx) |
| `MAX_CLIENTS` | `200` | Подключений на комнату (игроки и зрители) |
| `MAX_CLIENTS_PER_IP` | `6` | Подключений с одного IP |
| `MAX_ROOMS` | `300` | Комнат одновременно |
| `MAIN_SPARRING` | `1` | Сколько ботов выходит против одинокого игрока в общей арене; со вторым игроком бот уходит после раунда |
| `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET` | — | Вход через Discord для активности; без них маршруты `/discord/*` отвечают 503 |

Клиент в проде берёт путь до сервера из `VITE_SERVER_PATH` при сборке (по умолчанию `/api`),
а id приложения Discord для активности — из `VITE_DISCORD_CLIENT_ID`. Только сайту нужны
`VITE_WEBMANIFEST=1` (манифест, иконки из `logo/` и `service.js`, который снимает service worker
первой версии), `VITE_POLICIES=1` (страницы политики конфиденциальности и условий использования)
и `VITE_CNAME=openbomber.ru` (файл `CNAME` для GitHub Pages); без них этих файлов в сборке нет.
`VITE_OFFLINE=1` собирает игру без сервера (только против ботов), `VITE_SINGLEFILE=1` — всю игру
одним `index.html` (скрипты, стили, шрифты и картинки внутри; открывается и прямо с диска).
За nginx нужен `proxy_set_header X-Real-IP $remote_addr;`, на нём держатся лимиты по IP.

</details>
